4.2.4.4.
Application Fee (D1)
The amount of the Application Fee (D1) is seven thousand dollars ($7,000) for all project sizes.
The Application Fee is used to offset the cost of the Pre-Queue expenses and is non-refundable.
Failure to pay the (D1) Application Fee will result in withdrawal of the IR.
