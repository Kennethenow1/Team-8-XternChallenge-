5.5.2 Name Change Required Documents
1. Name Change Certificate
a. The Interconnection Customer must submit a Name Change Certificate to
complete a Name Change request.
Examples of a Name Change Certificate can be found in the Transfer of
Ownership Guide.
2. Updated W9 Form
a. The Interconnection Customer is required to update their W-9 form to reflect
the new entity name (Tax ID should not change).
b. The correct customer’s name and parent company must be accurately listed.

3. Attachment C NDA
a. The Interconnection Customer must update the Attachment C NDA list in
online tool. If the project is older and not available on the online tool,
customers must submit an updated Attachment C NDA list.
b. A fillable Attachment C NDA document can be found on the MISO public
website.
