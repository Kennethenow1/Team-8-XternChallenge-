4. Attachment C NDA
a. Customers must update the Attachment C NDA list in online tool. If the

an updated Attachment C NDA list.
b. A fillable Attachment C NDA document can be found on the MISO public
website.

5.5.1.2 GIA Assignment Requirements
1. Consent Assignment
a. If transfer takes place after a GIA is executed, a Consent to Assignment might
have to be executed by all parties to the GIA - per Article 19 of the GIA. A
Consent to Assignment template can be found on the MISO public website.
MISO legal can review the draft as needed.
b. Transfer Notice is not required for transfer post GIA.

2. Legal Documentation
a. A legally binding, executed document that demonstrates proof of ownership
for a transfer. The document must show the new entity name and show
evidence that a sale/transfer/assignment has taken place.
